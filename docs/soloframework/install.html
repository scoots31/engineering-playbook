Install the Solo Builder Framework

Two steps, once per machine. Works the same whether you use Claude Code, Cursor, or both.

Setup
1
Get the framework
Clones it to ~/Developer/engineering-playbook.
$ git clone https://github.com/scoots31/engineering-playbook.git ~/Developer/engineering-playbook
2
Run the install
Paste this into a Claude Code or Cursor chat — it reads its own instructions and sets itself up, including creating your separate Development Files folder for project work.
Claude Code Cursor Both — just run it in each
> Read ~/Developer/engineering-playbook/INSTALL.md and follow the instructions.
What happens
·
Creates Development Files next to the framework folder — that's where your own project work goes, kept separate from the framework's own code.
·
In Claude Code, it writes directly into your global config — nothing more to do.
·
In Cursor, it prints the setup text for you to paste into Settings → Rules → User rules — one paste, and it's done for every future session.
·
Once installed, say "guided mode" in any session to start.
